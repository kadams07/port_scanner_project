# Python Port Scanner

A simple Python port scanner built using the socket library.

## Features

- Checks whether the target host is reachable
- Scans common ports from 1 to 1024
- Detects open ports
- Displays the service name
- Uses socket programming in Python

## Technologies Used

- Python
- Socket Programming
- TCP/IP Networking

## How to Run

```bash
python port_scanner.py
